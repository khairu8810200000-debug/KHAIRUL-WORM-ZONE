# KHAIRUL WORM ZONE

Projek permainan Android ringkas berasaskan Kotlin dan Android Studio.

## Status

Repositori ini ialah tempat menyimpan kod sumber projek. APK hanya dianggap berjaya dibina selepas projek dibuka dan proses Build APK(s) selesai tanpa ralat di Android Studio atau GitHub Actions.

## Cara mula

1. Muat turun ZIP projek Android Studio dan ekstrak ke komputer.
2. Buka Android Studio, pilih **Open**, kemudian pilih folder projek yang mengandungi `settings.gradle.kts` atau `settings.gradle`.
3. Benarkan Gradle Sync selesai. Gunakan JDK 17 jika projek meminta JDK 17.
4. Pilih **Build > Build APK(s)**.
5. Jika berjaya, pilih pautan **locate** dalam notifikasi binaan untuk mencari APK.

## Kawalan dan iklan

Jika projek menggunakan Google AdMob, gunakan ID ujian semasa pembangunan. Gantikan dengan ID sebenar hanya selepas integrasi dan polisi AdMob disemak. Jangan klik iklan sebenar anda sendiri.

## Bantuan

Jika binaan gagal, salin mesej ralat penuh daripada tab **Build** Android Studio untuk semakan.
